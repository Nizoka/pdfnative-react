# Support

Thanks for using pdfnative-react! Here is how to get help.

## Questions & usage help

- Read the [README](README.md), the [Knowledge Base](docs/KNOWLEDGE_BASE.md)
  and the guides under [docs/](docs/) (typography, print, reproducible output,
  charts, server rendering, linting, recipes).
- Browse existing [GitHub Discussions](https://github.com/Nizoka/pdfnative-react/discussions)
  and [Issues](https://github.com/Nizoka/pdfnative-react/issues).
- Open a **Discussion** for how-to questions and ideas.
- A question about the rendered bytes themselves (fonts, shaping, PDF/A or
  PDF/X conformance, signing, extraction) is usually an engine question:
  [pdfnative](https://github.com/Nizoka/pdfnative) is where those answers live.

## Bug reports

Open a [bug report](https://github.com/Nizoka/pdfnative-react/issues/new/choose)
with a minimal reproduction (a `DocSpec` is ideal — it is plain JSON), the
output of `doctor()`, your `pdfnative-react`, `pdfnative`, `react` and Node
versions, and the expected vs actual behaviour. `npm run gate:fast` in a
checkout tells you quickly whether the tree is green before you dig.

## Security issues

See [SECURITY.md](SECURITY.md) — please report privately, not in public issues.
