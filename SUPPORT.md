# Support

Thanks for using pdfnative-react! Here is how to get help.

## Questions & usage help

- Read the [README](README.md) and the [Knowledge Base](docs/KNOWLEDGE_BASE.md).
- Browse existing [GitHub Discussions](https://github.com/Nizoka/pdfnative-react/discussions)
  and [Issues](https://github.com/Nizoka/pdfnative-react/issues).
- Open a **Discussion** for how-to questions and ideas.

## Bug reports

Open a [bug report](https://github.com/Nizoka/pdfnative-react/issues/new/choose)
with a minimal reproduction, your `pdfnative-react`, `pdfnative`, `react`, and
Node versions, and the expected vs actual behaviour.

## Security issues

See [SECURITY.md](SECURITY.md) — please report privately, not in public issues.

## Commercial support

For enterprise needs around the pdfnative ecosystem, contact
**hello@pdfnative.dev**.
